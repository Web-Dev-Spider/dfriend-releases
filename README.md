# dfriend releases

Installers for **dfriend**, the desktop app for LPG distributorships by Zuper Tech.

## Download

Get the latest installer from the **[Releases](https://github.com/Web-Dev-Spider/dfriend-releases/releases/latest)** page and run `dfriend_Setup_<version>.exe`.

## Updating

From version 4.5, dfriend checks for updates itself and offers to install them.
To update an older version by hand, close dfriend and run the new installer.
There's no need to uninstall first. Your agency profile, licence, customer
register and routes are kept.

## About this repository

This repository holds only the installers and the update information file
(`latest.json`) that dfriend reads. The application's source code is not
published here.

A licence is required to use dfriend without a watermark. Contact Zuper Tech.
